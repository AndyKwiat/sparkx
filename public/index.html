🎨 Art settings

How to add a Pixabay key (better vector art)
  1. Create a free account at pixabay.com.
  2. Open pixabay.com/api/docs while logged in — your key is shown in the key parameter.
  3. In the project folder, copy .env.example to .env and set PIXABAY_KEY=…
  4. Restart the server (npm start) and reload.
